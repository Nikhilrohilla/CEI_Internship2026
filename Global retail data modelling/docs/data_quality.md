# Data Quality Framework & Validation Report

## Overview

The **Data Quality Framework** continuously validates data integrity across the Silver and Gold Medallion layers. Every pipeline execution automatically logs compliance metrics to the `data_quality_results` database audit table.

---

## Data Quality Check Categories

1. **Completeness**: Ensures critical primary keys and business keys are non-null and non-empty.
2. **Uniqueness**: Detects duplicate business keys in dimension lookup tables.
3. **Validity**: Verifies that prices, sales amounts, and quantities are strictly positive numbers and dates are within valid ranges.
4. **Consistency**: Enforces financial calculation rules (`sales_amount = quantity * unit_price`).
5. **Referential Integrity**: Guarantees that 100% of transaction fact rows map to valid dimension records without orphaned keys.

## Audit Table Schema (`data_quality_results`)

```sql
CREATE TABLE data_quality_results (
    check_id VARCHAR,
    check_name VARCHAR,
    table_name VARCHAR,
    column_name VARCHAR,
    total_records BIGINT,
    failed_records BIGINT,
    failure_percentage NUMERIC(5,2),
    status VARCHAR,
    execution_timestamp TIMESTAMP
);
```
